# Invoice / Billing SaaS System

Production-ready Invoice & Billing SaaS application built with:

- Angular (Frontend)
- ASP.NET Core Web API
- SQL Server
- Stripe Payment Integration
- Clean Architecture
- JWT Authentication

This project is designed as a real SaaS product suitable for client projects and Upwork portfolio use.

---

# 🚀 Features

## Authentication
- User Registration
- Login
- JWT Authentication
- Role-Based Authorization

## Customer Management
- Create Customer
- Edit Customer
- Delete Customer
- Search Customers

## Invoice Management
- Create Invoice
- Invoice Items
- Tax Calculation
- Auto Invoice Number Generation
- Invoice Status Tracking

## Stripe Payment Integration
- Stripe Checkout Session
- Hosted Payment Page
- Stripe Webhook Integration
- Automatic Invoice Payment Updates

## Payments Module
- Payment History
- Stripe Session Tracking
- Payment Status Tracking

## Dashboard
- Revenue Overview
- Paid vs Pending Invoices
- Recent Invoices
- Invoice Analytics
